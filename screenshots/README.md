# App Store screenshots

Captured from the running app, not mockups. Each file is the full app window at 1440×900, PNG, with no mouse cursor in frame.

Note: these shots predate the title bar, so they show the old floating search box, not the current top bar. Recapture them before submitting to the App Store.

| File | What it shows |
| --- | --- |
| `01-welcome-board.png` | The first-run board: a note, swatches, a link card, a PDF card, a picture, an audio card and a video card, with a connector. Every element type at a glance. |
| `02-mood-board.png` | A mood board: autumn and coast photographs, colour swatches, a link card, a birds video and a birdsong audio card. |
| `03-research-board.png` | A research board: notes, a link card, photographs, a grouped cluster (select one, move them all), a waterfall video and a birdsong audio card. |
| `04-sketch-board.png` | Annotating a photo: a pen circle around a real photograph, pen strokes in several colours, swatches, a waterfall video and a short audio card. |
| `05-find-anything.png` | A large board at zoom 0.4 with one element selected by Tab, centred. A waterfall video and two audio cards are among the spread-out elements. |

To recapture: resize the window to 1440x900, open a board in Bowerbird and take a screenshot of the app window (on macOS, Cmd+Shift+4, then Space, then click the window). On Linux, `BOWERBIRD_WINDOW_SIZE=1440x900` forces the window to that size for a full-bleed shot, since the default window is 1280x850.
